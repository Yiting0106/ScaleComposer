# ScaleComposer

**ScaleComposer: Scale-Conditioned Composition for Source-Count Extrapolation in Physical Fields**

Project overview for the initial ICLR 2027 submission. This repository currently contains only this README; source code, datasets, and trained checkpoints are not included.

## Overview

ScaleComposer studies how to predict physical fields generated by multiple interacting sources when training observations cover only simpler configurations.

The task is **source-count extrapolation**: learn from configurations with at most two active sources and predict fields for configurations with three to six active sources. Each supervised training configuration contains at most one active source pair. Larger configurations contain several simultaneously active pairs, making their joint field an unseen compositional prediction task. Training may cover many distinct pairs across examples; the challenge is to predict their joint behavior when more sources operate together.

## Method

ScaleComposer combines three components:

- **Separate source and pair representations.** Shared encoders construct reusable representations of individual sources and unordered source pairs.
- **Attention conditioned on location and spatial scale.** Separate source and pair cross-attention modules select information for each prediction location and frequency band.
- **Spectrally constrained reconstruction.** A shared DeepONet generates field components, which are restricted to their assigned Fourier bands and combined with a separate field-mean correction.

Frozen single-source predictions provide prior information. The experiments distinguish using reference information as an input from adding a reference field at the output: both ScaleComposer and ScaleComposer w/o Ref retain reference inputs, while only the full model includes output reference addition.

## Evaluation

The study evaluates source-count extrapolation on measured ceiling-fan air-speed fields and six controlled two-dimensional numerical flow regimes, with prediction configurations containing up to six active sources.

The effect of output reference addition depends on the setting. It improves the reported measurement results, whereas omitting it reduces numerical MAE and RMSE with lower spatial correlation. The study also examines separate source/pair attention and per-band Fourier restriction through ablations.
